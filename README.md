# Java Calculator

A simple console-based calculator developed using Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Power calculation
- Square root
- Division by zero handling
- Continuous calculations
- Invalid choice handling

## Technologies Used

- Java
- Switch statement
- While loop
- Math class
- Conditional statements

## How to Run

1. Install Java on your computer.
2. Download or clone this repository.
3. Compile the program:

```bash
javac Calculator.java
```

4. Run the program:

```bash
java Calculator
```
